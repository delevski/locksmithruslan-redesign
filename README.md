# Locksmith Ruslan - Redesign Concept

A one-page redesign concept for [he.locksmithruslan.co.il](https://he.locksmithruslan.co.il/), an Israeli locksmith service. The UI is fully in Hebrew (RTL), built as a single self-contained static page (HTML/CSS/JS, no build step).

Live demo: https://delevski.github.io/locksmithruslan-redesign/

## What's inside

- Hero built around real search keywords (locksmith 24h, door opening, cylinder replacement)
- Emergency services strip, services grid, transparent price list with category filter
- Real reviews, service areas, FAQ, sticky call/WhatsApp CTAs (desktop + mobile)
- All contact details, prices and review quotes taken from the current live site

## Run

Open `index.html` or serve statically. No dependencies beyond Google Fonts (Heebo).
